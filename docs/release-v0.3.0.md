妮可 v0.3.0：Codex 原生宠物 + 对话互动技能。没有独立程序、额外窗口或后台定时器。

- 原生妮可继续使用 v2 图集与鼠标视线帧。
- 在 Codex 对话里说「妮可状态」即可查看本地饱腹度；首次安装/首次使用为 100%，每五分钟减少 1%，离线时间也会计入。
- 「喂妮可」增加 30%（最高 100%），回复可显示已生成的吃饭动图。状态独立保存，技能升级不重置。
- 「妮可陪我聊天」使用当前 Codex 会话陪聊；「看看这张图/看看屏幕」使用现有图片或在工具和权限允许时截图，不持续监控。
- 不需要额外聊天 API Key；正常 Codex 使用额度仍适用。脚本需要 Node.js 18+，无 npm 依赖。

新人复制到 Codex 即可：

> 请从 https://github.com/heyuyang04-ui/nicole-desktop-pet 安装最新版 skills/nicole-pet 技能，阅读 SKILL.md 并运行自带安装脚本。我要 Codex 原生妮可和对话互动技能，不要独立程序。已有安装请备份后更新，保留饱腹度数据，完成后告诉我如何选择妮可和使用互动指令。

推荐下载 `nicole-pet-skill.zip`；`nicole-codex-v2.zip` 仅包含外观，不包含互动技能。下载校验值见 `SHA256SUMS.txt`。

安装后完全退出并重开 Codex，在宠物设置选择「妮可」。可以在消息前加 `$nicole-pet` 明确调用技能。

边界：对话指令不绑定宠物单击、双击、右键菜单或旁边气泡；吃饭 GIF 展示在聊天中，不是强制原生角色播放。原生切换消失问题仍未确认修复。
