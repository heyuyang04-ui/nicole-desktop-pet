妮可 v0.4.0：原生资源结构重构，新增可选 Nicole Care 照料面板。

后续 v0.5.0 恢复独立 Nicole Pet 桌宠：角色、透明窗口和互动卡片由同一个 App 提供。v0.4.0 的原生包仍可单独下载。

- 原生包集中到 `output/nicole/`，新增九组动作图鉴、布局映射与只读诊断。仍可只安装两个原生资源文件。
- 原生安装器不再重写相同资源；更新采用完整临时文件替换，切换格式时保留旧图集；保留饱腹度与用户文件。
- 可选伴随面板支持饱腹度、点击喂食 +30%、吃饭动画、低饱腹度提示、可选系统通知、胶囊收起和置顶。面板和技能共用状态。
- 火山 Seedream 补画饥饿表情；已有六帧吃饭素材继续使用。不需要用户配置生图 Key 来安装或日常使用。
- 提供 Apple Silicon Mac、Intel Mac、Windows x64 面板 ZIP。未做 Apple 公证或商业签名，首次运行可能需要系统允许。

纯角色用户下载 `nicole-codex-v2.zip`；使用 Codex 对话照料功能选 `nicole-pet-skill.zip`；需要点击面板再另外下载相应系统的 `nicole-care` 包。已有用户更新技能时保留 `pet-state/nicole`，面板更新时先退出旧程序。

17 项核心测试覆盖共享状态、离线衰减、喂食、提醒去重、安装升级与诊断。macOS 真实面板测试覆盖喂食动画、单窗口、胶囊尺寸与置顶；跨平台构建由 CI 检查，Windows/Intel Mac 的桌面视觉效果仍待设备实测。

限制：面板独立运行，可手动放到角色旁，不会自动附着或修改原生右键菜单；陪聊按钮复制 Codex 指令。原生宠物切换后整块控件消失的问题尚未确证修复，当前可用「显示宠物」快捷键恢复，详见仓库问题记录。
