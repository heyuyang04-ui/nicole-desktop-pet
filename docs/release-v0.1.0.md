妮可桌宠首个预览版本，提供 Codex 原生皮肤与独立桌面互动两种方式。

- 独立版：单击聊天气泡，双击饱腹度卡片，右键喂食/看屏幕；所有互动在同一个透明窗口中展开。
- 首次饱腹度 100%，每五分钟减少 1%，喂食 +30%（封顶 100%），支持离线时间计算和六帧吃饭动画。
- 聊天/视觉模型分别设置；屏幕先预览再确认发送。没有内置 API Key。
- 原生包：11 行 v2 图集，支持 16 个视线方向。技能内包含旧版回退资源。

下载选择：`arm64-mac.zip` 用于 Apple Silicon；`mac.zip` 用于 Intel Mac。Windows 使用名称中标记 x64 或 arm64 的安装器。`nicole-pet-skill.zip` 是给 agent 安装的技能，`nicole-codex-v2.zip` 是原生角色资源。

macOS 源码和打包应用已通过模拟接口的集成测试。Mac arm64/x64 和 Windows x64/arm64 的 GitHub 构建全部通过。Windows 构建与实际交互测试是不同事项；本项目没有声称已在 Windows 桌面手动验证。真实模型需要自行配置。预览版本未正式签名/公证。

Codex 原生菜单没有自定义接口：互动功能来自独立程序，不会修改 Codex 的右键菜单。原生切换消失问题已有 v2 兼容性改动，但仍需用户实际回归，不能当作确认修复。
